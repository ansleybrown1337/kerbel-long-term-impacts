# Release 3.4.0 (`v3p4`)

This is the initial public release supporting the manuscript “Improving
Historical Reconstruction and Insight Through Complementary Bayesian and
Machine Learning Analysis of Long-Term Water-Quality Records.”

The release includes the cleaned 2011–2025 Kerbel record, the shared 528-event
data contract, Bayes v3p3, ML v3p4, complementary synthesis v3p4, current
figures, compact result tables, fitted model objects, and non-fitting tests.

Large draw-level products and platform-specific runtime artifacts are generated
locally and are not distributed through Git. Bayesian results retain their
diagnostic qualification: 28 divergent transitions and 20 finite parameters
with R-hat above 1.04 (maximum 1.068).

Before tagging, confirm author order and affiliations in `CITATION.cff`, add the
release date and publication/archive DOIs when available, run the release
checklist, and regenerate `CHECKSUMS.sha256`.
